# data/catalogo.json

- `ars`: 269 presentaciones del *Arsenal Farmacológico CESFAM Limache Viejo* (sin insumos): nombre, dosis y forma tal como vienen; `ci` apunta a la ficha del Compendio usada para sugerir pictogramas (−1 si no hay).
- `meds`: fichas de *Pingüino Compendio* (nombre, grupo, pautas de administración, manipulación y conservación con su fuente oficial: AEMPS-CIMA, DailyMed, etc.).

Para actualizar el arsenal, reemplaza las filas de `ars` y ejecuta `python build.py`.
